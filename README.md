# 喰種判別 - 東京喰種 設定判別アプリ

パチスロ「東京喰種（東京グール スマスロ）」用の個人利用向け設定判別Webアプリです。
HTML / CSS / JavaScript のみで動作し、サーバー不要・GitHub Pagesでそのまま公開できます。

## 主な機能

- 基本情報入力（店舗・日付・台番号・ゲーム数・投資回収、差枚は自動計算）
- 設定差要素の入力（＋/−ボタン・直接入力の両対応、片手操作しやすい大きめボタン）
- カード示唆・終了画面・トロフィーのチェック式入力
- 各項目の「1/○○」をリアルタイム自動計算
- ポアソン分布ベースのベイズ推定で設定1〜6の期待度・設定4以上/5以上/6期待度をグラフ表示
- 「ChatGPTへ解析依頼」ボタンで解析用テキストをワンタップでクリップボードコピー
- LocalStorageによる履歴保存・一覧・編集・削除・CSVエクスポート/インポート
- 入力途中でも自動保存、リロードしても復元

## 使い方（ローカル確認）

`fetch` で `settingData.json` を読み込むため、`file://` で直接開くとブラウザによっては
CORSエラーになります。ローカルで確認する場合は簡易サーバーを立ててください。

```bash
cd tokyo-ghoul-app
python3 -m http.server 8080
# http://localhost:8080 にアクセス
```

## GitHub Pagesへの公開手順

1. このフォルダの中身をリポジトリのルート（またはお好みのフォルダ）にコミット・プッシュ
2. GitHubリポジトリの Settings → Pages で公開ブランチ・フォルダを指定
3. 発行されたURLにスマホからアクセスしてホーム画面に追加すると、アプリのように使えます

## ⚠️ settingData.json の数値について（重要）

`settingData.json` に入っている数値は、公開されている解析情報サイトの内容を参考にしていますが、
以下の項目は**確度の高い実測値をそのまま使用**しています（`_source: "web"`）。

- レミニセンス（CZ）
- 大喰いのリゼ（上位CZ）
- エピソードボーナス
- AT直撃
- 通常時 赫眼リプレイ（下段リプレイ）

一方で、以下の項目は公開情報が乏しかったため**暫定値（プレースホルダー）**です（`_source: "estimate"`）。
実戦データが十分に集まったら、または信頼できる解析情報が見つかったら、必ず数値を見直してください。

- AT中 赫眼リプレイ
- 精神世界 10G / 20G / 30G / 40G / 50G

`settingData.json` はテキストエディタで直接編集できます。配列は
`[設定1, 設定2, 設定3, 設定4, 設定5, 設定6]` の順で「1/○○」の分母を入れてください。
数値が小さいほど「起こりやすい＝高設定に期待できる」項目として扱われます。

## 設定判別ロジックについて

`calc.js` では、各項目の観測回数をポアソン分布の実現値とみなし、設定1〜6それぞれを
仮定した場合の尤度を計算、全項目の対数尤度を合算してベイズ更新（事前分布は均等）する
簡易的な統計モデルを採用しています。あくまで実戦の目安・参考情報であり、
設定判別の結果を保証するものではありません。
